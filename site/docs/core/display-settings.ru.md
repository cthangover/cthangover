# Настройки экрана

`GameConfig` читает значения по умолчанию из `config/game_config.json`. `SettingsData` загружает профиль устройства из `user://settings.json`. При отсутствии профиля или ошибке разбора приложение использует значения по умолчанию. Сохранение сначала полностью записывает временный файл, затем заменяет им профиль.

| Параметр | Действие |
|---|---|
| `WindowMode`, `CurrentScreen`, `ResolutionWidth`, `ResolutionHeight` | Выбирают режим окна и монитор. Ширина и высота применяются в оконном режиме |
| `VsyncEnabled`, `MaxFps` | Управляют вертикальной синхронизацией и лимитом кадров. `MaxFps = 0` снимает лимит |
| `RenderScale3D` | Переопределяет `Viewport.Scaling3DScale`. Если значение отсутствует или равно `null`, применяется `rendering/scaling_3d/scale` из настроек проекта |

`DisplaySettingsService.Apply` применяет весь профиль, включая масштаб 3D. Масштаб задаёт внутреннее разрешение рендеринга 3D и позволяет снизить нагрузку на GPU. Godot применяет его к 3D-части вьюпорта. Размер окна и раскладка интерфейса 2D управляются отдельно.

## Просмотр и изменение текущих значений

`settings.read` возвращает `effective` с параметрами текущего процесса и `profile` с параметрами пользовательского профиля. `settings.apply` принимает `preset: "low_power"`, объект `values` или оба поля. `values` переопределяет соответствующие поля пресета.

| Поле в `values` | Допустимое значение |
|---|---|
| `max_fps` | Целое число от 0 до 1000 |
| `vsync_enabled` | Логическое значение |
| `render_scale_3d` | Число от 0,25 до 1,0 |

Пресет `low_power` ограничивает частоту 30 кадрами в секунду, а масштаб 3D значением 0,75. Если предел уже ниже, используется текущее значение. По умолчанию команда меняет настройки текущего процесса. Чтобы также записать их в профиль, передайте `persist: true`. Ответ содержит `restore_id` для отката через `settings.restore`. Вертикальная синхронизация недоступна в режиме headless.

```json
{"command":"settings.apply","values":{"max_fps":30,"render_scale_3d":0.75}}
```
