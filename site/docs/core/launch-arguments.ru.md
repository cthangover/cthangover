# Аргументы запуска

Передавайте аргументы приложения после разделителя `--` в команде Godot. Флаг записывается как `--ключ`, параметр со значением как `--ключ=значение`. Возьмите значение с пробелами в кавычки, чтобы оболочка передала параметр одним аргументом.

```shell
godot --path . -- --game=my_game --new --log-file="logs/dev run.log"
```

| Аргументы | Назначение |
|---|---|
| `--game=<id>`, `--new`, `--load=<slot>` | Выбрать коллекцию и начать новую игру или загрузить слот |
| `--with-mods=<id,id>`, `--all-mods` | Добавить идентификаторы к выбору или загрузить весь обнаруженный набор |
| `--scene=<name>`, `--frontend` | Запросить логическую сцену или оставить открытым интерфейс лаунчера |
| `--hot-reload`, `--no-hot-reload` | Включить или запретить отслеживание файлов. Явный запрет имеет приоритет |
| `--development-control`, `--no-development-control`, `--allow-debug-scripts` | Управлять возможностями [DebugHost](debug-host.md) при запуске |
| `--run-tests`, `--mod=<id>`, `--test-filter=<pattern>`, `--itest=<id,id>` | Выбрать тесты и интеграционные наборы. `--itest` можно передать несколько раз |
| `--with-test-suites`, `--choices=<id,id>`, `--timeout=<seconds>` | Подключить тестовые наборы, передать порядок автоматических ответов или установить таймаут драйвера |
| `--resource-atlas`, `--locale-atlas`, `--atlas-out=<path>` | Построить отчёт по ресурсам или локализации |
| `--log-file=<path>`, `--wait-for-debugger` | Переопределить путь лога или предложить подключить отладчик до запуска ядра |

## Чтение из C#

`GameLaunchArgs.Startup` хранит исходный снимок аргументов движка и приложения. `GameLaunchArgs.Current` возвращает действующий снимок. `Get<T>()` возвращает типизированный параметр или его значение по умолчанию, `Contains<T>()` проверяет наличие корректного аргумента, `GetAll<T>()` читает повторяющиеся аргументы приложения в исходном порядке. Для `--log-file` аргумент приложения имеет приоритет над аргументом движка.

```csharp
using Cthangover.Core.Games;
using Cthangover.Core.Games.LaunchParameters;

var launch = GameLaunchArgs.Current;
var extraMods = launch.Get<WithModsParameter>().Value;
var startFresh = launch.Contains<NewGameParameter>();
```

Каждый класс в `Core/Games/LaunchParameters` задаёт `Key`, `Documentation` и `Format`. Публичный конструктор без параметров даёт значение по умолчанию. Публичный конструктор со `string` разбирает часть после `=` или получает `null` для флага. Класс определяет тип и правила проверки значения. Флаг вроде `--all-mods` тоже представлен типизированным параметром.

## Чтение и изменение действующего снимка

`args.read` показывает исходные аргументы движка и приложения и действующие аргументы приложения. `args.catalog` выдаёт ключи, форматы, владельцев и значения до и после изменения. Для одного параметра укажите `key`. `args.set` принимает `arguments`, полный новый массив аргументов приложения, проверяет известные значения и заменяет действующий снимок. Включите в массив все аргументы, которые хотите сохранить. Исходный снимок и аргументы движка остаются доступны. Компоненты, читающие `Current`, увидят изменения при следующем чтении. Для настроек, проверяемых при запуске, например разрешения исполнения скриптов, нужен новый процесс.
