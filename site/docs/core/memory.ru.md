# Память и кеши

`ModMemoryService.Shared` показывает метрики общей управляемой кучи .NET и данные именованных хранилищ, подключённых к наблюдению. Каждое хранилище относится к своему поколению загрузки. Идентификатор владельца для ядра — `__core__`. Реестр держит слабые ссылки и удаляет область регистрации при выгрузке. Владелец держит сильную ссылку, управляет инвалидацией и освобождает свои ресурсы.

| API | Назначение |
|---|---|
| `IStorageMetrics` | Передавать число элементов и оценки затрат, если они доступны. `ReadPreview` может преобразовывать элементы в текст |
| `ICache` | Дополнять контракт метрик методом `Clear()` для воспроизводимых данных |
| `CreateList`, `CreateHashSet`, `CreateDictionary` в `ModMemoryScope` | Регистрировать наблюдаемые коллекции для хранимых данных |
| `CreateCache` в `ModMemoryScope` | Регистрировать кеш-словарь со счётчиками попаданий и промахов. Владелец определяет, когда инвалидировать записи или очистить кеш |
| `BoundedCache<TKey, TValue>` | Ограничивать кеш по числу записей и вытеснять запись, к которой дольше всего не обращались. Callback позволяет освобождать ресурсы кеша |
| `Track` и `Untrack` | Регистрировать и снимать с учёта собственное хранилище или адаптер с `IStorageMetrics` |

`ModMemoryService.Shared.For(assembly)` возвращает область сборки, загруженной конвейером модов. В автономных инструментах и тестах используйте `TryFor(assembly)`, поскольку у сборки может отсутствовать область. Кеш с лимитом или собственную коллекцию можно зарегистрировать через `Track`.

## Запросы через DebugHost

```json
{"command":"memory.stats","mod":"__core__","offset":0,"limit":20}
```

Без `mod` команда `memory.stats` выводит хранилища всех владельцев. `managed_heap_process` описывает всю управляемую кучу, включая запрос с фильтром по владельцу. Размеры отдельных хранилищ приблизительны и предоставляются ими самими. Обычная незарегистрированная коллекция .NET учитывается только в общей метрике процесса. Оценку нативной памяти и памяти GPU может сообщить владелец. Общая метрика кучи охватывает управляемую память.

```json
{"command":"memory.inspect","mod":"__core__","name":"<имя из memory.stats>","limit":10}
```

Для следующей страницы используйте `next_offset`, а для запроса к конкретной загрузке передайте `generation` из `memory.stats`. Лимит страницы — 100 записей. `entries: null` означает, что хранилище не предоставляет предпросмотр. Содержимое предпросмотра ограничено и может быть усечено. Обе команды только читают данные через контракт хранилища.
