# Загрузчики — `IModLoader`

Загрузчик открывает отдельную запись, найденную сканером. Метод `IsCanProvide(url)` проверяет, подходит ли запись этой стратегии. `CreateProvider` открывает хранилище и возвращает [`IModFileProvider`](../providers/). Конвейер обнаружения владеет провайдером и освобождает его при пропуске или замене кандидата.

```csharp
public interface IModLoader : IModDiscoveryProvider
{
    IModFileProvider CreateProvider(string url, string modName);
    string GetFallbackModId(string url, string entryName);
}
```

| Загрузчик ядра | Подходящие записи | Резервный ID |
|---|---|---|
| `FolderModLoader` | Существующий каталог | Имя каталога |
| `ZipModLoader` | Суффикс `.zip` без учёта регистра у записей вне существующих каталогов | Имя файла без расширения |
| `SevenZipModLoader` | Суффикс `.7z` без учёта регистра у записей вне существующих каталогов | Имя файла без расширения |

Резервный ID используется, только если корректный `manifest.json` не содержит `id`. Каталог с именем `example.zip` открывается загрузчиком каталогов. Для ZIP и 7z ядро может получать сохранённые пароли из пользовательского хранилища `user://archive_passwords.json`. Поддержка архивов встроена в рантайм и работает без установленного отдельно 7-Zip.

Порядок выбора между подходящими загрузчиками описан в разделе [Реестр обнаружения](../discovery-registry/).
