# Провайдеры — `IModFileProvider`

Провайдер предоставляет доступ к одному хранилищу по путям относительно его корня. Этим контрактом пользуются чтение манифеста, компилятор и загрузчики ресурсов. В ядре есть провайдеры каталогов и архивов ZIP и 7z. `SubdirModFileProvider` ограничивает доступ поддеревом существующего провайдера.

| Элемент | Контракт |
|---|---|
| `Mod`, `RootPath` | Идентификатор хранилища и путь к нему на диске, если он есть |
| `FileExists(path)` | Проверить наличие файла по относительному пути |
| `ListFiles(directory)` | Перечислить непосредственных потомков. Имена каталогов заканчиваются на `/`, скрытые записи пропускаются |
| `ReadFileText(path)`, `ReadFileBinary(path)` | Прочитать файл целиком как UTF-8 или байты. Для отсутствующего файла возвращается `null` |
| `OpenStream(path)` | Открыть поток, которым владеет вызывающий код. Поток из архива может поддерживать чтение только вперёд |
| `GetFileSystemPath(path)` | Вернуть физический путь, если он доступен. Архивные провайдеры возвращают `null` |
| `ResolveIncludePath(includePath, currentPath)` | Разрешить путь включаемого файла относительно исходного файла |
| `Dispose()` | Освободить провайдер и открытый архив |

Закрывайте потоки до освобождения провайдера. Для крупных файлов используйте `OpenStream`, если вызывающий код может читать данные потоком. Для обработки набора архивных файлов провайдеры ядра также реализуют `IModFileSequence.VisitFiles` с последовательным чтением. Если потребителю нужен физический путь, учтите, что файлы могут находиться внутри архива.
