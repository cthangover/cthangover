# Конфигурация ядра — mod_config.json

Ядро читает `config/mod_config.json` при запуске. В нём хранятся параметры компиляции, поиска ресурсов, кешей и локальной диагностики.

| Поле | Назначение |
|---|---|
| `use_assembly_cache` | Позволяет переиспользовать сборки между процессами. По умолчанию включено. При отключении процесс может продолжать использовать уже загруженный артефакт |
| `development_control` | Включает локальный именованный канал DebugHost для того же пользователя. Явный запрет передаётся через `--no-development-control` |
| `development_discovery` | Необязательный путь к файлу обнаружения DebugHost. При пустом значении файл не публикуется |
| `texture_extensions`, `texture_groups` | Расширения и каталоги, по которым `TextureResolver` ищет текстуры в доступных провайдерах |
| `shader_extensions` | Допустимые расширения шейдеров |
| `audio_extensions` | Поле схемы. Загрузчик конфигурации использует значения из кода `.ogg` и `.wav` |
| `catalog_ignore_patterns` | Маски исключений для `install_sha256`. Поставляемый файл исключает `.*`, `bin` и `obj` |
| `catalog_urls`, `catalog_token_files` | Адреса каталогов и пути к файлам токенов для точных URL |
| `run_mod_tests`, `mod_test_exclude` | Разрешение запуска тестов из конфигурации и список исключённых ID. Тесты можно запросить явно через `--run-tests` |
| `cache.root` | Путь к дисковому кешу. По умолчанию `user://mod_cache/` |
| `cache.max_sizes` | Лимиты числа записей по ключу фабрики. Отсутствующий или отрицательный лимит заменяется значением вызывающего кода |

Список пользовательских каталогов хранится в `user://catalog_servers.json`. После первого сохранения этот файл задаёт источники вместо `catalog_urls`, в том числе когда сохранён пустой список.

См. [сборку и кеш компиляции](/docs/core/), [DebugHost](/docs/core/debug-host) и [поиск ресурсов](/docs/resources/).
