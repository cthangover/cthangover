# Уровень 1 — Игрок: патчим персонажа

<div class="qs-meta">
<span>Текстовый редактор</span>
<span>5 минут</span>
<span>Без кода</span>
</div>

Вы усилите персонажа Marao — увеличите здоровье, атаку и добавите способность «Ошеломление» — через систему патчей. Ни одной строчки кода, только JSON.

---

## Шаг 1: Создаём папку мода

Каждый мод живёт в своей папке внутри `mods/` (рядом с игрой) или `user://mods/` (папка пользовательских данных, на Windows — `%APPDATA%\cthangover\mods`). Создайте:

```filestree
mods/
└── quickstart_player/
    ├── manifest.json
    └── patches/
        └── character.json
```

---

## Шаг 2: manifest.json

Каждому моду нужен манифест. Создайте `mods/quickstart_player/manifest.json`:

```jsonc
{
  "id": "quickstart_player",        // Уникальный идентификатор мода, пиши на английском языке
  "name": "Бафф Марао",             // Отображаемое имя, показываемое в меню управления модами
  "description": "Мой первый мод!", // Описание, видимое в списке модов и каталоге
  "author": "player",               // Автор мода (произвольная строка)
  "depends": ["cthangover_game"]  // Зависимость от основной игры (чтобы не требовалось вручную располагать порядок загрузки мода)
}
```

Сам файл манифеста обязателен — без него мод будет пропущен, — но ни одно поле не является строго обязательным: если `id` не указан, идентификатором становится имя папки. Заполнять `id` и `name` всё же рекомендуется. Игра сама найдёт папку мода, но в игру он попадёт только после подключения (шаг 4).

---

## Шаг 3: Патч на персонажа

Создайте `mods/quickstart_player/patches/character.json`:

```jsonc
{
  "Items": [
    {
      "Id": "Marao", // ИД персонажа, которого нужно пропатчить (определён в основном моде)

      "Health": 5000, // Новые значения свойств — перезаписывают оригинальные
      "Attack": 1200,
      "Point": 2,

      "Actions$add": ["physics/stun"] // $add добавляет элементы в массив
    }
  ]
}
```

### Как это работает

- **`"Id": "Marao"`** — цель патча: персонаж с идентификатором `Marao` (определён в моде `cthangover_game`).
- **`"Health": 5000`**, **`"Attack": 1200`** и **`"Point": 2`** — перезаписывают поля персонажа. Новые значения заменяют старые.
- **`"Actions$add": ["physics/stun"]`** — суффикс `$add` означает «добавить элементы в массив». Действие `physics/stun` добавляется к списку. Стандартные `physics/attack` и `physics/defence` остаются. Ошеломление стоит 2 ОД — поэтому мы подняли и `Point`.

> Подробнее о патчах: [Patches](site/docs/mods/patches/) и [Array Operations](site/docs/mods/patches/arrays-and-identity).

---

## Шаг 4: Подключаем мод к игре

Игра загружает не все установленные моды, а только те, что входят в коллекцию игры. Новый мод нужно добавить в неё один раз:

1. В главном меню откройте **«Моды и коллекции»** → вкладка **«Коллекции»**.
2. На карточке игры **Cthangover** нажмите **«Изменить схему»**.
3. Выделите на схеме любую механику (например, **«Сюжет»**) и нажмите **«Добавить мод»**.
4. Найдите в списке свой мод (по имени из `manifest.json`) и нажмите **«Добавить»**.
5. Нажмите **«Сохранить»** и подтвердите. Изменения вступят в силу при следующем запуске игры.

> **Для разработчиков.** При запуске из исходников мод можно подключить без меню, флагом: `godot --path . -- --game=cthangover --new --with-mods=quickstart_player`.

---

## Шаг 5: Запускаем и проверяем

Перезапустите игру и начните новую. Войдите в любой бой — у Marao теперь:

- **5000 HP** вместо 16
- **1200 ATK** вместо 5
- **2 ОД** вместо 1
- Третье действие **«Ошеломление»** рядом с «Простая атака» и «Защита»
