# Уровень 2 — Моддер: сцена на DSL

<div class="qs-meta">
<span>JSON + DSL</span>
<span>15 минут</span>
<span>Без кода</span>
</div>

Вы создадите мод с собственной сценой — баром с диалогом, выборами и переходами. А заодно добавите вход в бар в существующую сцену города, не трогая оригинальные файлы.

---

## Шаг 1: Структура мода

Создайте папку и базовые файлы:

```filestree
mods/
└── quickstart_modder/
    ├── manifest.json
    ├── scenes/
    │   └── my_alko_bar.json              # Наша новая локация - алко-бар!
    ├── scenarios/
    │   ├── my_alko_bar.scenario          # Сценарий внутри алко-бара, дадим игроку возможность повзаимодействовать с новой локацией
    │   └── town_entry_override.scenario  # Дополняем сцену города, чтобы добавить переход в нашу новую локацию
    ├── backgrounds/
    │   └── my_alko_bar/
    │       └── bg.png                    # Картинка интерьера бара
    └── sounds/
        └── locations/
            └── alkobar/
                └── bar_ambient.ogg       # Фоновый звук шума в баре
```

---

## Шаг 2: manifest.json

`mods/quickstart_modder/manifest.json`:

```jsonc
{
  "id": "quickstart_modder",                           // ИД мода
  "name": "Мой алко-бар",                              // Имя мода, отображаемое в меню модов
  "description": "Добавляет сцену алко-бара в городе", // Описание мода, отображаемое в меню модов
  "author": "modder",                                  // Автор мода
  "depends": ["cthangover_game"]                     // Зависимость от основной игры (чтобы не требовалось вручную располагать порядок загрузки мода)
}
```

---

## Шаг 3: Описание сцены

`mods/quickstart_modder/scenes/my_alko_bar.json`:

```jsonc
{
  "name": "my_alko_bar",                              // Придумываем новый, уникальный идентификатор сцены (используется в switch_scene), это будущая сцена.
  "defaultBackground": "my_alko_bar/bg",              // Путь к PNG-фону внутри backgrounds/ (без расширения)
  "defaultAmbient": "locations/alkobar/bar_ambient",  // ID фонового звука этой локации (путь внутри sounds/ без расширения), например "шум в баре", который будет запускаться при входе на локацию
  "defaultScenario": "scenarios/my_alko_bar.scenario" // Сценарий по умолчанию, который будет запускаться в этой сцене, если ничего другого нет
}
```

| Поле | Значение |
|---|---|
| `name` | Уникальный ID сцены. Используется в `switch_scene` |
| `defaultBackground` | Путь к фону внутри `backgrounds/` (без расширения) |
| `defaultAmbient` | Фоновый звук: путь внутри `sounds/` без расширения. Пустая строка — без звука |
| `defaultScenario` | Путь к `.scenario` файлу, который запустится при входе |

---

## Шаг 4: Фон и звук

Положите изображение в `mods/quickstart_modder/backgrounds/my_alko_bar/bg.png`, а фоновый звук — в `mods/quickstart_modder/sounds/locations/alkobar/bar_ambient.ogg`.

Подойдёт любое PNG-изображение. Игра поддерживает шейдерное освещение и время суток — фон будет автоматически освещаться.

> Если нет своего изображения, временно скопируйте `mods/cthangover_game/backgrounds/home/kitchen.png` → `mods/quickstart_modder/backgrounds/my_alko_bar/bg.png`. Без звука тоже можно: укажите `"defaultAmbient": ""`.

## Шаг 5: Сценарий на DSL

`mods/quickstart_modder/scenarios/my_alko_bar.scenario`:

```scenario
scene: my_alko_bar
priority: 10
---
text "Вы заходите в полупустой бар."
text "За стойкой скучает бармен."

:menu
select "[Что будете делать?]"
option "Подойти к стойке" -> :bar
option "Уйти" -> :leave

:bar
text "Бармен кивает вам."
text "— Чего желаете?"
goto -> :menu

:leave
switch_scene town_entry
end
```

### Что здесь происходит

- **`scene:`** / **`priority:`** — заголовок: к какой сцене относится сценарий и в каком порядке он запускается. Заголовок отделяется от тела строкой `---`.
- **`text`** — показывает строку диалога. Параметр `key=` — ключ локализации (здесь не нужен: без него показывается сам текст).
- **`select`** — открывает меню выбора. Текст в кавычках — подсказка.
- **`option`** — вариант выбора. `-> :label` — куда перейти при выборе.
- **`:menu`**, **`:bar`**, **`:leave`** — метки для переходов.
- **`goto -> :menu`** — безусловный переход: после разговора с барменом снова открывается меню.
- **`switch_scene`** — переносит игрока в другую сцену.
- **`end`** — завершает сценарий.

## Шаг 6: Расширяем город (приоритет сцены)

Теперь добавим вход в бар в сцену города, **не трогая** оригинальные файлы `cthangover_game`.

`mods/quickstart_modder/scenarios/town_entry_override.scenario`:

```scenario
scene: town_entry
priority: 1
---
select "Из приоткрытой двери бара доносится музыка..."
option "Зайти в бар" -> :alko_bar
option "Пройти мимо" -> :pass

:alko_bar
switch_scene my_alko_bar
end

:pass
end
```

### Почему это работает

У сцены `town_entry` теперь несколько сценариев:

| priority | Сценарий | Мод |
|---|---|---|
| `1` | наш `town_entry_override` | `quickstart_modder` |
| `10`–`30` | встреча с Мураками (только пока выполняются их условия `condition:`) | `cthangover_murakami` |
| `40` | стандартное меню города | `cthangover_game` |

При входе на сцену движок запускает первый подходящий сценарий в порядке возрастания `priority` — с **наименьшего**. Когда сценарий заканчивается без смены сцены, запускается следующий. Поэтому:

- «Зайти в бар» — `switch_scene` уводит игрока в бар;
- «Пройти мимо» — наш сценарий просто завершается (`end`), и дальше всё идёт как в оригинальной игре: сюжетная сцена Мураками или стандартное меню города.

Так мод добавляет новое, ничего не ломая. Если бы наш сценарий сам рисовал меню города, он перекрыл бы и сюжет, и чужие моды.

> Подробнее: [Scene Priority System](site/docs/mods/scenes/).

## Шаг 7: Подключаем мод к игре

Игра загружает не все установленные моды, а только те, что входят в коллекцию игры. Добавьте мод в неё:

1. В главном меню откройте **«Моды и коллекции»** → вкладка **«Коллекции»**.
2. На карточке игры **Cthangover** нажмите **«Изменить схему»**.
3. Выделите на схеме любую механику (например, **«Сюжет»**) и нажмите **«Добавить мод»**.
4. Найдите в списке свой мод (по имени из `manifest.json`) и нажмите **«Добавить»**.
5. Нажмите **«Сохранить»** и подтвердите. Изменения вступят в силу при следующем запуске игры.

---

## Шаг 8: Проверяем

Перезапустите игру:

1. Зайдите в город — первым появится выбор «Зайти в бар» / «Пройти мимо».
2. Нажмите «Зайти в бар» — вы в своей сцене `my_alko_bar` с фоном, шумом бара, диалогом и выборами.
3. Выберите «Уйти» — возвращаетесь в город.
4. Выберите «Пройти мимо» — игра продолжается как обычно.

> **Для разработчиков.** Из исходников сцену можно открыть сразу, без прохождения пролога: `godot --path . -- --game=cthangover --new --with-mods=quickstart_modder --scene=town_entry`.
